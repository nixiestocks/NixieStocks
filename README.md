# NixieStocks — AI Stock Market Analyst

NixieStocks is a Streamlit stock-market analysis and forecasting app with worldwide company-name search, interactive charts, technical indicators, AI recommendations, sector-related stocks, daily returns, market news, comparison tools, and an optional LSTM deep-learning forecast.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

Use these deployment settings:

- Project: `NixieStocks`
- Branch: `main`
- Main file path: `app.py`
- Python: `3.11`

> Educational analysis only. This project does not provide financial advice.
